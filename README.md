## Featured work

### [AgriPheno Fusion](https://github.com/hishammohamed445/AgriPheno-Fusion)

A tested multimodal crop-phenotyping MVP that combines aligned RGB/NIR imagery with soil and weather sensors. It extracts canopy cover, NDVI distributions, image-quality indicators, VPD, and stress features through a CLI and FastAPI.

`Python` `OpenCV` `NumPy` `FastAPI` `Pydantic` `pytest` `Docker` `GitHub Actions`

### [VisionSafe360](https://github.com/s0ltan12/VisionSafe360)

A graduation team project for real-time industrial safety monitoring. I contributed to the computer-vision integration and unified workflow for PPE, falls, forklift proximity, restricted zones, dashboards, and alerts.

`YOLO` `OpenCV` `FastAPI` `Real-time inference` `Video analytics`

### [Donut Invoice Intelligence](https://github.com/hishammohamed445/Donut-Invoice-Intelligence)

An OCR-free document-understanding pipeline covering SROIE preprocessing, Donut fine-tuning, checkpointing, single and batch inference, a FastAPI service, and a browser client. Large datasets and weights are intentionally excluded.

`PyTorch` `PyTorch Lightning` `Transformers` `Donut` `FastAPI` `Docker`
