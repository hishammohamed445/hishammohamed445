## Selected engineering work

### VISION & DECISION (V&D) — Industrial Safety Intelligence

An edge-AI safety platform designed to turn existing CCTV infrastructure into real-time industrial safety intelligence. The system combines detection, tracking, safety rules, event aggregation, alerts, and an HSE review workflow for use cases such as PPE compliance, restricted zones, falls, and forklift-worker proximity.

`Python` `YOLO` `OpenCV` `ByteTrack` `FastAPI` `PostgreSQL` `Redis` `Docker` `Real-time video analytics`

> Product and engineering work includes edge inference, backend services, incident workflows, dashboards, and production-readiness testing.

### [AgriPheno Fusion](https://github.com/hishammohamed445/AgriPheno-Fusion)

A tested multimodal crop-phenotyping MVP that combines aligned RGB/NIR imagery with soil and weather sensors. It extracts canopy cover, NDVI distributions, image-quality indicators, VPD, and stress features through both a CLI and FastAPI service.

`Python` `OpenCV` `NumPy` `FastAPI` `Pydantic` `pytest` `Docker` `GitHub Actions`

### [Donut Invoice Intelligence](https://github.com/hishammohamed445/Donut-Invoice-Intelligence)

An OCR-free document-understanding pipeline built around Donut. It covers SROIE preprocessing, model fine-tuning, checkpointing, single and batch inference, a FastAPI service, and a lightweight browser client.

`PyTorch` `PyTorch Lightning` `Transformers` `Donut` `FastAPI` `Docker`

### [Mini Agent](https://github.com/hishammohamed445/mini-agent) — In Progress

A small learning-focused foundation for experimenting with AI-agent and RAG application architecture, beginning with a lightweight FastAPI service and an environment prepared for iterative agent capabilities.

`Python` `FastAPI` `Uvicorn` `AI Agents` `RAG`
